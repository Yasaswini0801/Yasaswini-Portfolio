## 🚀 How to Run Locally

You do not need to install anything! Simply:

1. Open the folder `Yasaswini-Portfolio` in File Explorer.
2. Double-click `index.html` to open it in your default web browser (Chrome, Edge, Firefox, Brave, etc.).
3. Alternatively, if you use VS Code, install the **Live Server** extension, right-click `index.html`, and select **Open with Live Server**.

## 🌐 Free Deployment via GitHub Pages

1. Create a new repository on your GitHub account (`https://github.com/Yasaswini0801/portfolio` or similar).
2. Push this folder's contents to the repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Yasaswini's portfolio"
   git branch -M main
   git remote add origin https://github.com/Yasaswini0801/<repo-name>.git
   git push -u origin main
   ```
3. In your GitHub repository:
   - Go to **Settings** &rarr; **Pages**.
   - Under **Build and deployment** &rarr; **Branch**, select `main` and `/ (root)`.
   - Click **Save**.
4. Within 1-2 minutes, your website will be live at `https://<your-username>.github.io/<repo-name>/`.
